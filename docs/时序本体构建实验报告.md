# 时序本体构建实验报告

## 目标

Nano-OntoPrompt 将表格、文档和传感器记录映射为本体实例，并把可追溯的实例图写入按 ontology 隔离的 FalkorDB。C-MAPSS 是原型回归数据，不代表已确定的工厂生产数据源。

## 实现

- `ordinal`：C-MAPSS 的 `cycle` 映射为 `event_seq`，不伪造日期。
- `instant`：ISO 时间解析为 UTC；非法时间记录 issue，不猜测修复。
- `interval`：保存 `valid_from/valid_to`，结束早于开始时报错。
- Observation/Event 节点使用稳定 ID；关系写入使用批量 `MERGE`，重复导入幂等。
- `POST /api/v2/ontologies/{id}/graph/temporal/import` 支持 C-MAPSS/Scania adapter。
- `GET .../graph/temporal/relations` 支持关系类型、主客体、序列、当前/历史筛选。

## 演示步骤

1. 启动 FalkorDB 和 Nano 后端，登录后创建或选择 ontology。
2. 调用 temporal import，C-MAPSS 行至少包含 `unit_id`、`cycle` 和传感器字段。
3. Graph → 数据实例，按实体类型和 cycle 范围查看节点；关系选择“全部历史/当前有效”。
4. 节点/边详情查看 `event_seq`、来源和有效区间。

## 验收边界

C-MAPSS 是快速回归；BTS snippet 是后续正式时序基准，需使用其 Brick gold metadata 比较映射准确率。BTS 官方仓库：[DIEF_BTS](https://github.com/cruiseresearchgroup/DIEF_BTS)。NASA 数据入口：[C-MAPSS](https://data.nasa.gov/dataset/?organization=nasa&res_format=ZIP&tags=ivhm&tags=phm&tags=prognostics)。本阶段不宣称下载全量 BTS 或完成大规模性能测试。
