# 多模态本体构建实验报告

## 范围

本阶段复用 Nano 已有 MarkItDown、OCR、PDF/Office 和图片上传能力，把 CSV/XLSX 与文档、图片提取结果放入同一 Construction Run。新增 `ExtractedFragment` 记录片段、定位信息、提取方法、状态和错误；`MediaItem` 作为媒体资产记录。

## 证据规则

跨模态边只能由明确业务 ID、文件元数据或文本/OCR 中可定位匹配建立。没有证据时，0.8B 模型不得猜边。来源在 `EvidenceRef.extractor` 中区分 `rule|llm|ocr|bridge_fallback`。

## API

- `POST /api/v2/multimodal/fragments` 保存 OCR/MarkItDown 片段。
- `GET /api/v2/multimodal/fragments/{media_item_id}` 查看片段。
- `GET /api/v2/assertions/{assertion_id}/provenance` 查看节点/边证据。

本阶段没有加入视觉大模型，不声称图表理解、目标识别或音视频语义理解；这些属于后续 VLM 方向。
