# 阶段验收记录

## 环境

- 日期：2026-08-30（Asia/Shanghai）
- 分支：`codex/temporal-construction-demo`
- Web：`http://127.0.0.1:5173`
- API：`http://127.0.0.1:8000`
- 图后端：FalkorDB（宿主端口 6381，容器通过 `host.docker.internal` 访问）
- Worker：Celery，任务名 `ontoprompt.temporal_construction`
- 数据：BTS Site B 交互投影，来源 [DIEF_BTS](https://github.com/cruiseresearchgroup/DIEF_BTS)

## 复跑命令

```bash
docker compose up -d db redis backend celery_worker frontend
curl http://127.0.0.1:8000/health
# 登录获取临时 Bearer token 后进入 /data/temporal，或调用：
POST /api/v2/ontologies/{ontology_id}/temporal/runs
{
  "source": "bts_site_b",
  "adapter": "bts",
  "time_kind": "instant",
  "event_time_column": "event_time",
  "entity_id_column": "stream_id"
}
GET /api/v2/construction-runs/{run_id}
GET /api/v2/ontologies/{ontology_id}/temporal/snapshot?limit=300
GET /api/v2/ontologies/{ontology_id}/temporal/timeline?limit=120
GET /api/v2/ontologies/{ontology_id}/temporal/diff?from_at=...&to_at=...&limit=300
GET /api/v2/ontologies/{ontology_id}/temporal/growth?limit=80
```
