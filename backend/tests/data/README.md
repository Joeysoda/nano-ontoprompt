# UCI Steel Industry Energy Consumption

`Steel_industry_data.csv` is the public UCI Machine Learning Repository dataset 851, downloaded from the official UCI archive on 2026-10-11.

Citation: V E, S., Shin, C., & Cho, Y. (2021). *Steel Industry Energy Consumption*. UCI Machine Learning Repository. https://doi.org/10.24432/C52G8C.

The dataset is licensed under [Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/). UCI describes 35,040 observations, no missing values, and measurements from a small-scale steel industry in South Korea. The data is used here for a local energy sensitivity validation. Tariff amounts used by the test are illustrative assumptions and are not included in the dataset.
