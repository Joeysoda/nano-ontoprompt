# Plan B 盲测验证工具包（未预演问题）

依据：Plan B 第 7 节 Product validation，以及 Palantir [Ontology design validation](https://www.palantir.com/docs/foundry/ontology/ontology-design-validation/)。目标是让新用户、领域用户和 Agent 在通用工具里自己找答案，记录正确性、操作路径、耗时、困惑和求助情况。截图和自动化测试不能代替这一步。

## 执行规则

1. **实现者不当被试**，也不在旁边提示操作路径。
2. 标准答案不在仓库里。主持人在测试前运行
   `python backend/scripts/blind_validation_answers.py --pdm <azure_pdm 目录> --out answers.json`，
   把答案自己保管；被试和 Agent 都看不到。
3. Agent 只拿到下面的题目原文和平台访问能力，题目里不加任何提示词。
4. 环境：Azure PdM 全量数据（模拟数据）、frePPLe 演示数据和 UCI 钢铁数据，按照对应验收测试的方式加载，规则和 Action 也已发布。每组被试使用一套全新的环境，因为 Q5、Q6 会修改状态。

## 题目（原样发给被试）

**设备运维（Azure PdM）**
1. 2015 年哪台设备的 comp4 故障次数最多？
2. machine-017 最近一次维护是哪一天，换的是哪个部件？
3. model3 型号的设备一共有几台？
4. 振动告警里，哪台设备的告警段最多？
5. machine-099 目前有几条还没解决的电压告警？
6. 给第 4 题找到的那台设备安排一次维护，并确认它的维护状态已经变化。

**排程（frePPLe 演示）**
7. 哪位操作员能处理"上漆椅子"类订单？
8. 当前排程方案里，Carl 的总工时是多少？
9. 如果所有订单数量翻倍、每人工时上限仍是 120 小时，排程结果会怎样？
10. 在不改动正式数据的前提下，对比场景和正式数据中 Demand 07 分配给谁。

**能耗（UCI 钢铁）**
11. 2018 年有多少个周末的日用电量高于周末日用电量的中位数？
12. 一小时平均用电超过 99.04 kWh 的时段一共有几段？

## 记录表（每位被试、每道题一行）

|---|---|---|---|---|---|---|---|---|---|

## 判读

- 同一道题有 ≥2 名被试选错类型或理解错链接方向：优先检查元数据的描述和命名，不要先改界面。
- Q6、Q10 是写操作和场景隔离题。如果有人把场景里的修改当成了正式数据，属于高优先级的产品问题（Plan B 不变量 8）。
- Agent 的错误要单独归类：如果是因为属性描述不清而选错属性，修的是元数据，不是提示词。
